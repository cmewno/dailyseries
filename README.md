# Daily Series

Минималистичное веб-приложение для ведения ежедневных записей и отслеживания серий (streaks). Пишите каждый день одну строку о том, что вы сделали, и наблюдайте, как растёт ваша серия.

## Возможности

- Добавление записи на сегодня (одна строка текста)
- Автоматическое сохранение в localStorage браузера
- Отображение истории записей с датами
- Подсчёт текущей серии (подряд идущих дней с записями)
- Удаление записей
- Минималистичный деловой дизайн

## Использование

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в любом современном браузере.
3. Начните добавлять свои ежедневные записи.

## Размещение на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите файлы проекта.
3. Перейдите в настройки репозитория → Pages.
4. В разделе "Source" выберите ветку `main` и папку `/root`.
5. Сохраните. Через несколько минут приложение будет доступно по ссылке.

## Технологии

- Чистый HTML, CSS, JavaScript
- Шрифт Inter (Google Fonts)
- localStorage для хранения данных
